# RABBIT-HOPPING — Catalog Card

**Reversible packet addressing + nested-rotation translator + memory rebuild engine + quadratic/memristor cell simulation.**

## What it is

A software system that:
1. Addresses sources with stable identity + generated center + wrappers (opposite-parity neighbors).
2. Retains route family, K, polarity, orientation, branch — so routes are invertible.
3. Rebuilds memory from partial cues via rabbit-hop neighborhood + Hopfield completion + Boltzmann fill.
4. Adds quadratic energy, memristor magnetic hold, and differential-triggered reinjection.
5. Simulates the full three-cell stack (BC-DC / TC-AC / QC-RC) with R27 target and physics constraints in the virtual breadboard.

## What it is NOT

- Not a proven physical rotation or scale law.
- Not a working hardware cell. No APK, no netlist, no measured D1/D2/D3, no B-field data.
- Not a musical instrument or planetary model. The 12-label adapter is labeling only.
